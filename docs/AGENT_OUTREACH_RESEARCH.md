# Real-estate agent outreach research — 2026-05-14

Source-of-truth artifact for the first wave of AHO PO outreach to
publicly-listed real-estate agents in the four jurisdictions where
B2B cold-outreach is legally permissive enough for personal-inbox
1-to-1 contact: **United States, Mexico, Australia, Singapore**.

Produced via the `agent-outreach` subagent ([.claude/agents/agent-outreach.md](../.claude/agents/agent-outreach.md))
running in Mode 1 (market research). Each report capped at 5 named
example agents per the agent's anti-list-building refusal rules.

## How to use this doc

1. Pick a target market.
2. Visit the **top public sources** listed for that market in your
   own browser (logged in to LinkedIn where relevant).
3. Manually pick 10-20 specific agents per market based on what you
   see — fit for AHO's value prop (active poster, suburb specialist,
   bilingual when relevant, mid-volume).
4. For each agent you choose, ask the `agent-outreach` subagent
   (Mode 2) to draft a personalized 3-channel pitch (email +
   LinkedIn DM + WhatsApp opener).
5. Send each manually from your **personal Gmail / Outlook**, not
   from `info@advertisehomes.online`. Cold outreach must never touch
   the AHO transactional sending domain.

The 5 named example agents per market below are illustrative starting
points — not exhaustive lists.

  - Monterrey / Guadalajara — skip first wave.
- **Founder Rate ($19/mo)** anchors well for AMPI agents — below most agents' existing Inmuebles24 destacado fees ($25-40/mo equivalent).

## 🇸🇬 Singapore

### Top public sources

1. **CEA Public Register** — https://www.cea.gov.sg/aceas/public-register
   State-mandated, statutorily public directory of every CEA-licensed agency + salesperson. Updated daily. CEA number `R123456A` format; shows agency, completed transactions (last 24mo), disciplinary actions. **Most authoritative.**
2. **PropertyGuru SG — Find Agent** — https://www.propertyguru.com.sg/property-agent-singapore/find-agent
   #1 portal; ~11,000+ profiles with CEA number, agency, listing count, ratings. Most-active leaderboard at https://www.propertyguru.com.sg/property-agent-singapore/most-active-agents.
3. **99.co — Singapore Agents** — https://www.99.co/singapore/agents
   #2 portal. Major agencies: Huttons, PropNex, ERA, OrangeTee & Tie, SRI, KW.
4. **EdgeProp SG — Property Agents** — https://www.edgeprop.sg/property-agents
   #3 portal. Investor / analytical audience → experienced agents.
5. **LinkedIn — Singapore filter** — https://www.linkedin.com/search/results/people/?keywords=%22real%20estate%20agent%22&geoUrn=%5B%22102454443%22%5D (geoUrn 102454443 = Singapore)

### Example agents (illustrative — 5)

1. **Kelvin Fong** — PropNex CEO (July 2025); head of PNG team (3,000+ agents); private residential / new launches. https://www.srx.com.sg/agent/50122/kelvinfong/agent-listings
2. **Mohamed Ismail Gafoor ("Ismail Gafoor")** — PropNex Executive Chairman + co-founder. https://www.propnex.com/our-leadership
3. **Stuart Chng** — Navis Living Group / OrangeTee & Tie. Executive Group District Director, 280+ agents; private condo / investment. https://www.stuartchng.com/
4. **Jeremy Lim** — Huttons Asia. Group District Director, ~170-salesperson team; luxury condo. https://www.propertyguru.com.sg/agent/jeremy-lim-436989
5. **Gillian Tan** — PropNex; MBA (NUS); residential. https://sg.linkedin.com/in/gillian-tan

### Languages

English primary. Mandarin (and Chinese dialects) strong secondary — many agents bilingual EN/ZH explicitly marketing to local + mainland Chinese + overseas Chinese buyers.

### Market notes

- **Universal licensing.** Every legitimate agent must be CEA-registered; CEA number `R123456A` is the unique key. **Require it during AHO onboarding** — scammer filter + clean uniqueness key.
- **Extreme agency concentration.** 4 firms dominate: PropNex (~12,600 agents), ERA (~8,700), Huttons (~5,700), OrangeTee & Tie (~4,000+). Together >30,000 of Singapore's ~36,000 licensed agents.
- **Team-leader cascading.** Big agencies organize as divisions/groups/PNG-style teams (Stuart Chng 280, Kelvin Fong 3,000, Jeremy Lim 170). **Winning one team leader → cascade across hundreds.** This is the highest-leverage outreach pattern in Singapore.
- **B2B is normal.** PDPA + Spam Control Act permit professional B2B email at publicly listed business addresses. Singapore agents already pitched constantly by CRM/portal/photography vendors — bar is relevance + brevity, not consent.
- **Heavy social-media usage already.** FB/IG/TikTok/YouTube. PropNex + Huttons run formal social-media training. **Pro Automation $99 pitch: "save time on what you already do," not "try something new."**
- **AHO product-language gap.** Singapore is English + Mandarin. AHO platform is EN/ES only. Either (a) lead with English and note Spanish for LATAM expansion, or (b) flag Mandarin support as v2 roadmap.
- **Avoid bulk-export vendors** (e.g. SPAD claiming 36k verified contacts) — PDPA purpose-limitation grey area. CEA register + portal profiles are clean.
